# チャットAI設定画面仕様

## LM Studio モデル別ツール設定とテンプレート修正案内

- LM Studioのモデルごとにツール使用の有効・無効を切り替える。既定は有効とし、設定画面の保存操作で設定を永続化する。
- 無効時は天気・検索・位置・音量・アプリ起動・タスク・メモを含むすべてのツール定義を送らない。他のモデルやエンジンの設定は変更しない。
- 無効時はツール操作を実行済みと装わないよう指示する。一時的なタイマーは引き続き利用できる。
- チャットテンプレートエラーは内容を特定できる場合にツール無効化と修正案内を示す。自動再試行やテンプレートの自動変更は行わない。
- 既知の`format_type_argument`未定義に対する修正例を表示する。すべてのモデルに適用できるものではなく、バックアップと既存マクロの確認後に利用者がLM Studio側で手動適用する。

## LM Studio の思考機能

- 「思考機能を有効にする」の設定によって、ユーザープロンプトやシステムプロンプトに`/no_think`を追加しない。
- 過去履歴をLM Studioへ送信する際は、思考機能のオン・オフにかかわらず履歴中の単独の`/no_think`を除去する。元の保存履歴は変更しない。
- 既存の`reasoning_format: none`と`include_reasoning: false`の要求設定は維持する。
- LM Studio SDKの思考設定をMastraから利用する経路は未実装であり、現在の要求設定だけでは思考停止を保証しない。

## LM Studio モデルのコンテキストサイズ変更

- LM StudioをチャットAIエンジンに選択した場合、モデル名の下にコンテキストサイズ入力欄と「指定サイズで再ロード」ボタンを表示する。
- モデル選択後、LM Studioの管理APIから現在ロード中のコンテキストサイズとモデルの最大サイズを取得して表示する。未ロードの場合は既定の入力値を8192とし、モデルの最大値がそれ未満なら最大値を用いる。
- 入力できるサイズは1024以上の整数で、モデルの最大値が判明している場合はその値以下とする。
- ボタン操作前に対象モデル、指定サイズ、および進行中の会話が中断される可能性を確認する。
- 再ロード要求は認証済みのAPI経路で、`localhost`またはループバックアドレスをHostに持つ同一オリジンのJSON要求に限る。接続元IPはNitro内で取得できない場合があるため判定に使わない。モデルが複数インスタンスでロードされている場合は拒否し、他のモデルやインスタンスを解放しない。
- 既に指定サイズでロードされている場合は解放・再ロードを行わない。
- 再ロード時は既存インスタンスのコンテキスト以外の対応するロード設定を引き継ぐ。新しいサイズでのロードに失敗した場合は、可能なら元のサイズへの復旧を試みる。
- 成否を設定画面に表示し、成功後は現在のロード状態を再取得する。設定値の保存操作やチャット送信ごとに自動再ロードは行わない。
- LM Studioのモデル管理には`/api/v1/models`、`/api/v1/models/unload`、`/api/v1/models/load`を使用し、チャット送信は従来どおりOpenAI互換APIを利用する。
